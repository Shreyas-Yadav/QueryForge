# Database Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `.env`-based database credentials with a `databases.json` list plus a login screen where the user picks a database and user and types the password at runtime.

**Architecture:** `connections.py` loads and validates `databases.json`. `db.py` owns the single active login — the pool *and* the `OracleProfile` it was built from — installed by `db.replace_pool()` only after a successful ping. `session.py` is the thin coordinator for login/logout (pool + schema cache). `web/app.py` exposes `/databases`, `/login`, `/logout`, `/session` and gates `/query`. The UI shows a login card until a session exists.

**Tech Stack:** Python 3.12, FastAPI, pydantic v2 / pydantic-settings, python-oracledb 4 (thin mode), pytest, vanilla JS.

**Spec:** `docs/superpowers/specs/2026-10-15-db-login-design.md`

**Deviations from spec (deliberate, small):**
- The active `OracleProfile` lives in `db.py` next to the pool (not in `session.py`). `db` → `session` → `db` would be a circular import, and the profile and pool must change atomically anyway. `session.py` keeps the lock and the login/logout coordination.
- Non-ORA-01017 login failures return 502 with `Could not connect to <host>:<port>/<service>: <driver message>` (spec said "Can't reach"). Some of these, e.g. ORA-28000 account locked, are not reachability problems, so the wording is neutral.

## Global Constraints

- Passwords are never written to disk and never logged; `OracleProfile.password` and `LoginIn.password` use `Field(repr=False)`.
- `databases.json` is git-ignored; `databases.example.json` is committed.
- `databases.json` default path `databases.json` (relative to CWD), overridable via `DATABASES_FILE`.
- Entry fields: `name` (req, unique case-insensitive), `host` (req), `port` (int 1–65535, default 1521, strict int), `service_name` (req), `schema` (opt), `users` (req, non-empty, unique case-insensitive). Unknown keys rejected.
- DSN built with `oracledb.makedsn(host, port, service_name=service_name)`.
- No cloud/wallet entries in the JSON for now; `OracleProfile` keeps its wallet fields.
- Single user, local only; no cookies/tokens.
- Run tests with `uv run pytest`.

## Review Focus

1. Account locked/expired at login (ORA-28000) — user expects to see the Oracle reason, not "Invalid username or password". Test: Task 3 `test_other_oracle_error_shows_driver_message`.
2. Username typed/listed in a different case (`SHREYAS` vs `shreyas`) — Oracle treats them the same, so login should accept it. Test: Task 3 `test_user_match_is_case_insensitive`.
3. Editing `databases.json` while the server runs — the next `/databases` should reflect it without restart. Test: Task 3 `test_databases_file_is_reread`.
4. Logging in again as a different user — the old pool must be closed and the schema cache cleared, or the agent advertises the previous user's tables. Test: Task 3 `test_relogin_replaces_previous_pool`.
5. Database name looked up with different case/whitespace from a hand-crafted request. Test: Task 1 `test_find_is_case_insensitive`.

```python
"""The databases offered on the login screen, read from ``databases.json``.

Each entry names a database and the Oracle users allowed to log in to it. The
file holds no secrets — passwords are typed at login and kept only in memory —
but it is still git-ignored because it describes your own machines.

The file is re-read on every call so edits apply without restarting the server.
"""

from __future__ import annotations

import json
from pathlib import Path

import oracledb
from pydantic import BaseModel, ConfigDict, Field, TypeAdapter, ValidationError, field_validator

from .config import get_settings


class DatabasesFileError(Exception):
    """``databases.json`` is missing, is not valid JSON, or fails validation."""


class DatabaseEntry(BaseModel):
    """One connectable database: where it listens and who may log in to it."""

    model_config = ConfigDict(extra="forbid", frozen=True, str_strip_whitespace=True)

    name: str = Field(min_length=1)
    host: str = Field(min_length=1)
    port: int = Field(1521, ge=1, le=65535, strict=True)
    service_name: str = Field(min_length=1)
    # "schema" shadows a BaseModel attribute, so it is stored as schema_name.
    schema_name: str | None = Field(None, alias="schema")
    users: list[str] = Field(min_length=1)

    @field_validator("users")
    @classmethod
    def _users_are_distinct(cls, users: list[str]) -> list[str]:
        if any(not u for u in users):
            raise ValueError("usernames must not be blank")
        folded = [u.upper() for u in users]
        if len(set(folded)) != len(folded):
            raise ValueError("duplicate usernames (Oracle usernames are case-insensitive)")
        return users

    @property
    def dsn(self) -> str:
        """Full TCP connect descriptor for this host/port/service."""
        return oracledb.makedsn(self.host, self.port, service_name=self.service_name)


_ENTRIES = TypeAdapter(list[DatabaseEntry])


def _describe(error: ValidationError) -> str:
    return "; ".join(
        f"{'.'.join(str(part) for part in err['loc'])}: {err['msg']}"
        for err in error.errors()
    )


def load_databases(path: Path | None = None) -> list[DatabaseEntry]:
    """Read and validate the databases file (``DATABASES_FILE`` by default)."""
    path = path or get_settings().databases_file
    try:
        raw = json.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError as e:
        raise DatabasesFileError(
            f"{path} not found — copy databases.example.json to {path.name} and edit it."
        ) from e
    except json.JSONDecodeError as e:
        raise DatabasesFileError(f"{path} is not valid JSON: {e}") from e

    try:
        entries = _ENTRIES.validate_python(raw)
    except ValidationError as e:
        raise DatabasesFileError(f"{path} is invalid: {_describe(e)}") from e

    if not entries:
        raise DatabasesFileError(f"{path} lists no databases.")
    seen: set[str] = set()
    for entry in entries:
        key = entry.name.casefold()
        if key in seen:
            raise DatabasesFileError(f"{path} is invalid: duplicate database name '{entry.name}'.")
        seen.add(key)
    return entries


def find(name: str, path: Path | None = None) -> DatabaseEntry:
    """Look up an entry by name (case-insensitive). Raises ``KeyError`` if absent."""
    wanted = name.strip().casefold()
    for entry in load_databases(path):
        if entry.name.casefold() == wanted:
            return entry
    raise KeyError(name)

from __future__ import annotations

import pytest

from queryforge import db


class FakeConn:
    def __init__(self, pool: "FakePool") -> None:
        self.pool = pool
        self.call_timeout = None
        self.current_schema = None

    def __enter__(self) -> "FakeConn":
        return self

    def __exit__(self, *exc) -> bool:
        return False

    def ping(self) -> None:
        if self.pool.ping_error is not None:
            raise self.pool.ping_error


class FakePool:
    def __init__(self, profile, ping_error: Exception | None = None) -> None:
        self.profile = profile
        self.ping_error = ping_error
        self.closed = False

    def acquire(self) -> FakeConn:
        return FakeConn(self)

    def close(self, force: bool = False) -> None:
        self.closed = True


class PoolFactory:
    """Stands in for ``db._create_pool``. Set ``next_error`` to fail the next ping."""

    def __init__(self) -> None:
        self.created: list[FakePool] = []
        self.next_error: Exception | None = None

    def __call__(self, profile) -> FakePool:
        pool = FakePool(profile, ping_error=self.next_error)
        self.next_error = None
        self.created.append(pool)
        return pool

    factory = PoolFactory()
    monkeypatch.setattr(db, "_create_pool", factory)
    return factory

    """Every test starts and ends logged out."""
    db.close_pool()
    yield
    db.close_pool()

class NotLoggedIn(RuntimeError):
    """No database login is active — log in from the web UI first."""


_pool: oracledb.ConnectionPool | None = None
_profile: OracleProfile | None = None
_pool_lock = threading.Lock()


def get_pool() -> oracledb.ConnectionPool:
    """Return the active login's connection pool."""
    pool = _pool
    if pool is None:
        raise NotLoggedIn("Not connected — log in to a database first.")
    return pool


def active_profile() -> OracleProfile:
    """Return the profile of the active login."""
    profile = _profile
    if profile is None:
        raise NotLoggedIn("Not connected — log in to a database first.")
    return profile


def _pool_kwargs(profile: OracleProfile) -> dict[str, Any]:
    """Build ``create_pool`` arguments for one connection profile."""
    kwargs: dict[str, Any] = dict(
        user=profile.user,
        password=profile.password,
        dsn=profile.dsn,
        min=1,
        max=4,
        increment=1,
        homogeneous=True,
    )
    if profile.uses_wallet:
        # mTLS: PEM wallet (thin mode). Plain host/port/service entries have no
        # wallet, so they connect with the DSN alone.
        kwargs.update(
            config_dir=profile.config_dir,
            wallet_location=profile.wallet_location,
            wallet_password=profile.wallet_password,
        )
    return kwargs


def _create_pool(profile: OracleProfile) -> oracledb.ConnectionPool:
    return oracledb.create_pool(**_pool_kwargs(profile))


def _close(pool: oracledb.ConnectionPool) -> None:
    """Close a pool, logging rather than raising.

    ``force=True`` because a plain close raises if any connection is still
    checked out — which is exactly the case when the user logs out or switches
    login while a query is streaming. The deliberate action should win.
    """
    try:
        pool.close(force=True)
    except Exception as e:  # noqa: BLE001 — never block a login change
        logger.warning("Error closing connection pool: %s", e)


def replace_pool(profile: OracleProfile) -> None:
    """Connect as ``profile`` and make it the active login.

    The new pool is built and pinged before anything is swapped, so a bad
    password or an unreachable listener raises here and leaves the current login
    exactly as it was.
    """
    global _pool, _profile
    logger.info(
        "Connecting to Oracle [%s] user=%s dsn=%s", profile.target, profile.user, profile.dsn
    )
    new_pool = _create_pool(profile)
    try:
        with new_pool.acquire() as conn:
            conn.ping()
    except BaseException:
        _close(new_pool)
        raise
    with _pool_lock:
        old, _pool, _profile = _pool, new_pool, profile
    if old is not None:
        _close(old)


def close_pool() -> None:
    """Log out: close the active pool (if any) and forget its profile."""
    global _pool, _profile
    with _pool_lock:
        old, _pool, _profile = _pool, None, None
    if old is not None:
        _close(old)


def _schema_name() -> str:
    """The schema the agent reads — the entry's schema if set, else the user."""
    profile = active_profile()
    return (profile.schema_name or profile.user).upper()

"""The single active database login (one local user, one login at a time).

Logging in or out must change two things together: the connection pool in
:mod:`queryforge.db` and the schema overview cached in the agent's system prompt
(:mod:`queryforge.prompt`). Otherwise the agent keeps advertising the previous
user's tables. This module is the one place that does both, under one lock.
"""

from __future__ import annotations

import threading

from . import db, prompt
from .config import OracleProfile
from .connections import DatabaseEntry

_lock = threading.Lock()


def login(entry: DatabaseEntry, user: str, password: str) -> None:
    """Connect to ``entry`` as ``user``. Raises the driver error on failure,
    leaving any existing login untouched."""
    profile = OracleProfile(
        target=entry.name,
        user=user,
        password=password,
        dsn=entry.dsn,
        schema_name=entry.schema_name,
    )
    with _lock:
        db.replace_pool(profile)
        prompt.clear_schema_cache()


def logout() -> None:
    with _lock:
        db.close_pool()
        prompt.clear_schema_cache()


def status() -> dict[str, object]:
    """Who is logged in to what, plus a live reachability probe."""
    try:
        profile = db.active_profile()
    except db.NotLoggedIn:
        return {
            "logged_in": False,
            "database": None,
            "user": None,
            "reachable": False,
            "detail": "not logged in",
        }
    try:
        db.ping()
        reachable, detail = True, "connected"
    except Exception as e:  # noqa: BLE001 — surface why, don't crash the UI
        reachable, detail = False, str(e)
    return {
        "logged_in": True,
        "database": profile.target,
        "user": profile.user,
        "reachable": reachable,
        "detail": detail,
    }

@app.post("/login")
def login(payload: LoginIn) -> dict[str, object]:
    """Connect as the chosen user. The password is held in memory only."""
    _load_databases()  # surface a broken databases.json as 500, not "unknown database"
    try:
        entry = connections.find(payload.database)
    except KeyError:
        _audit_login(payload.database, payload.user, "rejected")
        raise HTTPException(
            status_code=400, detail=f"Unknown database '{payload.database}'"
        ) from None

    wanted = payload.user.strip().upper()
    user = next((u for u in entry.users if u.upper() == wanted), None)
    if user is None:
        _audit_login(entry.name, payload.user, "rejected")
        raise HTTPException(
            status_code=400,
            detail=f"User '{payload.user}' is not configured for '{entry.name}'",
        )
    if not payload.password:
        _audit_login(entry.name, user, "rejected")
        raise HTTPException(status_code=400, detail="Password is required")

    try:
        session.login(entry, user, payload.password)
    except oracledb.Error as e:
        if "ORA-01017" in str(e):
            _audit_login(entry.name, user, "invalid credentials")
            raise HTTPException(status_code=401, detail="Invalid username or password") from None
        _audit_login(entry.name, user, "unreachable")
        raise HTTPException(
            status_code=502,
            detail=f"Could not connect to {entry.host}:{entry.port}/{entry.service_name}: {e}",
        ) from None

    _audit_login(entry.name, user, "success")
    return session.status()

    ## Connecting

    ```

    ```

    `databases.json` is a list; each entry is one database:

    | Field | Required | Meaning |
    |---|---|---|
    | `name` | yes | Shown in the dropdown; must be unique |
    | `host` | yes | Listener host, e.g. `localhost` |
    | `port` | no | Listener port (default `1521`) |
    | `service_name` | yes | Oracle service, e.g. `AIWORLD` or `FREEPDB1` |
    | `schema` | no | Schema the agent reads (default: the logged-in user) |
    | `users` | yes | Oracle users offered for this database |

    A connect string such as
    `(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=localhost)(PORT=1539))(CONNECT_DATA=(SERVICE_NAME=AIWORLD)))`
    maps to `"host": "localhost", "port": 1539, "service_name": "AIWORLD"`.

    On the login screen pick the database and user and type the password. The
    password is held **only in memory** — never written to disk or logged — so you
    log in again after restarting the server. Edits to `databases.json` show up the
    next time the login screen loads.

    > **Keep the server on localhost.** There is one login for the whole process and
    > no cookies, so anyone who can reach the port uses your database session. Don't
    > run it with `--host 0.0.0.0`.
    ````
